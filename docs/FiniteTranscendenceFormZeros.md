# Homogeneous-form zeros over finite-transcendence extensions

Import `NormForms.FiniteTranscendenceFormZeros` (or `NormForms`) for
`MvPolynomial.exists_nonzero_zero_of_trdeg_eq_of_single_form_bound`.
Let `k` and `K` be arbitrary fields with `[Algebra k K]`, and let
`r n : ℕ`. Assume `Algebra.trdeg k K = (n : Cardinal)` and the following
**uniform single-form premise over `k`**, for *every* positive degree `a`,
every arity `t` strictly larger than `a ^ r`, and every homogeneous-label-`a`
form `p`:

```lean
∀ (a t : ℕ) (p : MvPolynomial (Fin t) k),
  0 < a → a ^ r < t → p.IsHomogeneous a →
    ∃ x : Fin t → k, x ≠ 0 ∧ MvPolynomial.eval x p = 0
```

For `0 < d` and the **strict** inequality `d ^ (r + n) < m`, any
`f : MvPolynomial (Fin m) K` with `f.IsHomogeneous d` has a nonzero
`K`-point zero:

```lean
∃ x : Fin m → K, x ≠ 0 ∧ MvPolynomial.eval x f = 0
```

With `open MvPolynomial`, use the theorem directly:

```lean
obtain ⟨x, hx, hfx⟩ :=
  exists_nonzero_zero_of_trdeg_eq_of_single_form_bound
    r n htrdeg hsingle d m hd hsize f hf
```

The hypothesis constrains a homogeneous **label**, not an exact nonzero
total degree; the zero form is included. Neither `k` nor `K` needs to be
infinite. There is no finite-generation, separability, characteristic,
nonzero-form, or simultaneous-zero assumption. The algebraic remainder of
`K` over its transcendence basis may be infinite. Cases `n = 0`, `r = 0`,
`d = 1`, and the minimal permitted arity `m = d ^ (r + n) + 1` are included.
This theorem does not assert a converse, sharpness, a `C_i` classification,
or a zero shared by several forms.

## Proof outline and dependencies

The proof obtains a finite transcendence basis of cardinality `n`, enumerates
its generators, and builds a tower of intermediate fields by adjoining them
one at a time. At the bottom, the base field transfers across the canonical
field equivalence. At each successor stage, algebraic independence makes the
new generator transcendental over the previous stage: its adjunction is
equivalent to a rational-function field over that stage. The existing
`NormForms.RatFuncFormZeros` single-form theorem increments the exponent once,
and a field equivalence transports the bound to the next stage. At the top,
`K` is algebraic over the field generated by the entire basis. The existing
`NormForms.AlgebraicExtensionFormZeros` single-form theorem passes the
exponent-`r + n` bound through that (possibly infinite) algebraic extension.

Only `exists_nonzero_zero_of_trdeg_eq_of_single_form_bound` is new public API;
the tower construction and equivalence-transport lemmas are private. The
five ordinary-import examples in
[`NormFormsTests.FiniteTranscendenceFormZeros`](../NormFormsTests/FiniteTranscendenceFormZeros.lean)
check the general theorem, minimal arity, zero form, `n = 0`, and the
`r = 0`, `d = 1` boundary. They add no production theorem.

## Reproduce with pinned dependencies

The original single-form proof and client are Formal Frontier project work;
subsequent adaptation into this library and independent review are separate
roles. Use the toolchain and official dependencies pinned by the root Lake
files. Fetch the matching mathlib cache successfully before building:

```sh
lake exe cache get
lake build NormForms NormFormsTests
```

The commands are reproduction instructions, not evidence for a changed
candidate or a source-coverage decision.
